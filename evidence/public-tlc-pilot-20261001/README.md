# Resource pilot

One measured trial and no warm-ups for each of the six existing adapters at 10,000 public records. Pilot timings are not pooled with the repeated public-data evaluation and are not manuscript plotted points. All six executions and 66 historical-state checks passed.

Pilot implementation developed during the subsequent scale pilot: additional untimed verification hashes and reduced retention of decoded oracle copies were introduced before the repeated study. The repeated study archives its frozen source; this pilot is retained for acquisition/correctness/resource history, not as repeated performance evidence. The internal spec's payload_bytes=8 in pilot records is a validation placeholder; real records are variable-length JSON.
